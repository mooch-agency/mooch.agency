How to get it ↓

Install

Copy the prompt, paste it into Claude Code.

Prompt 
Install the Say Less plugin:

1. Run `claude plugin marketplace add gichigi/say-less`
2. Run `claude plugin install say-less@say-less`
3. Verify with `claude plugin list`

If step 1 fails with a clone or auth error: this is an invite-only beta, so I need repo access from Tahi first. Check `gh auth status`.

When done, tell me to restart my session and ask any question to see the style.

Or run it yourself:

Shell 
claude plugin marketplace add gichigi/say-less
claude plugin install say-less@say-less
