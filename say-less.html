Method

This page is a feel test, not the benchmark. The 71%/80%/10-10 numbers above are measured on the real Claude Code CLI; this demo calls Claude directly so it can run in a browser.

Benchmark: 10 held-out prompts, 3 trials each, hermetic (no personal CLAUDE.md, settings, or plugin reaches either arm). Words counted in code, every token with a letter or digit, code included, never judged by a model. Reasoning, tool use, and answer completeness are unchanged; only the reply gets shorter.

Full method and results: benchmark/RESEARCH.md. Run the real Claude Code version yourself: github.com/gichigi/say-less.
